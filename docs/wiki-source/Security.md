# Security Policy

## Supported Versions

This repository is maintained on the `main` branch. Security fixes are applied there first.

## Reporting A Vulnerability

Please do not open public GitHub issues for security vulnerabilities.

Use GitHub's private vulnerability reporting flow from the repository Security tab when it is enabled. If that option is unavailable, contact the maintainer privately and include:

- a clear description of the vulnerability
- steps to reproduce it
- affected components or environments
- any proof-of-concept details needed for validation

We will try to acknowledge valid reports promptly, investigate them, and coordinate a responsible fix before public disclosure.

## Disclosure Guidance

- Avoid posting secrets, tokens, credentials, or exploit details in public issues or discussions.
- If you accidentally shared a secret in the repository or an issue, rotate it immediately and notify the maintainer through a private channel.
